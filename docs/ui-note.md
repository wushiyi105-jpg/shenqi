# UI 说明：审契

- **谁在什么时刻打开**：给小团队签前的条款核对。
- **首屏任务句**：签之前，这两版差在哪。
- **主操作**：按「导入两版合同 → 对条款差异 → 生成谈判清单」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：律师审阅的双页纸；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：律师审阅的双页纸。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给小团队签前的条款核对：每条待复核项回到原条款和版本，能备注、提问、生成修订草稿，也能标记已交专业人士复核。
